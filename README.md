# AR-BETA-T-EGARCH-model
AR-BETA-T-EGARCH model used for the visualization and predictions of the exchange rate of pounds and USD. 
The repository has two files: functions_ats.R, which contains the necessary functions to run the model, and rate_model_uk.R which manages and imports the data and produces the images. The used data is available on: 
https://fred.stlouisfed.org/series/exusuk

Board of Governors of the Federal Reserve System (US), “U.S. Dollars to U.K. Pound Sterling Spot
Exchange Rate [EXUSUK].” FRED, Federal Reserve Bank of St. Louis, 2026.
